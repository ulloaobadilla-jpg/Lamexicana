# La Mexicana Pucón

Sitio estático para publicar en GitHub Pages.

## Publicación

1. Sube esta carpeta a un repositorio de GitHub.
2. En el repositorio ve a Settings > Pages.
3. En Source selecciona GitHub Actions.
4. El workflow de la carpeta .github/workflows/deploy-pages.yml hará el despliegue automáticamente.

La web se servirá desde la raíz del repositorio.
